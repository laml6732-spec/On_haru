# On_HARU · 말씀 읽기와 묵상 우선 (v2 Preview)

## 목적
기본 경험은 말씀 읽기, 조용히 묵상하기, 필요한 경우 생각 남기기다. 암송은 별도 선택 기능이며, 오늘 암송하지 않아도 실패·미완료로 표시하지 않는다. 기존 Write·Check-in·Plan·Focus·Review 구조 유지.

## 실제 UI 배치
| 위치 | 표시 | 동작 |
|---|---|---|
| Write, 기존 노트 입력 아래 | 오늘의 말씀 + 장절 + 읽기와 묵상 | 선택된 말씀 읽기로 진입, 과거 날짜에서는 숨김 |
| Focus의 Devotion | 말씀 읽기·묵상 | 기존 Focus 타이머 변경 없이 성경 읽기 화면 열기 |
| Focus 읽기 화면 | 장절, NLT 원문, 허가된 경우 개역개정 번역 전환, 묵상 질문 | 읽기/생각 남기기 기본, 암송은 하단 보조 링크 |
| Review의 Archive 바깥 분리된 서재 | 읽은 말씀 N/100, 다시 읽기 N | 전체/읽음/다시 읽기 검색·필터, 암송 여부는 각 항목 상태에만 |

## 읽기 화면 규칙
- 읽기와 가리고 암송을 동급 탭으로 두지 않는다. 읽기만 기본으로 표시한다.
- 성경 본문 16px, line-height 1.63, 절 번호는 위첨자로 구분. 가짜 카드·새 강조색 없이 DESIGN.md 토큰 재사용.
- 묵상 질문은 `어떤 표현이 마음에 남나요? 오늘의 삶과 이어지는 부분이 있나요?`로 제한하며 답변 의무 없음.
- 기본 주요 버튼은 `생각 남기기`. 기존 Write의 노트 입력기로 연결한다.
- 새 노트가 비었을 때만 본문 reference를 제목으로 채우고 Scripture 태그를 활성화하며 개인 기록으로 분류한다. 기존 메모 초안·제목·연결 일정은 덮어쓰지 않는다. 자동 저장 완료를 주장하거나 노트를 자동 제출하지 않는다.
- 보조 선택: `읽음 표시`, `다시 읽기 저장`, `다음 말씀`, `100개 말씀 보기`.
- `암송 연습 (선택)`을 눌러야 본문 가리기·자가 점검·암송 완료 버튼을 볼 수 있다.
- 매일 새 구절로 자동 전환하거나 성경 읽기를 일정/할 일/Check-in으로 취급하지 않는다.

## 데이터/호환성
- 기존 저장 키 kona.scripture-memory.v1 유지. 상태 마이그레이션이나 기존 사용자 기록 삭제 없음.
- 새 선택 필드는 read_at(첫 읽음 표시 시각), last_read_on(오늘 표시 여부), saved_for_later(다시 읽기 저장)뿐.
- 기존 status / memorized_at / attempts / next_review_on 등의 선택적 암송 기록 보존. 묵상 화면의 첫 화면에 암송 마감일을 표시하지 않는다.
- 기존 Write 사용자 기록 구조를 사용한다. 읽기만 하면 메모를 자동 생성하지 않는다.
- NKRV 개역개정 본문 파일은 저작권 이용 범위가 해결되기 전 미포함. 파일이 없으면 NLT 본문만 표시하며 한국어 본문이 존재하는 척하지 않는다.
- 학습 기록은 기존 별도 JSON 내보내기/복원 구조를 유지한다.
