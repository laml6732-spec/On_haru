### 직접 본 화면
- 390px 라이트 **Review Daily**: Plan 부모 일정 아래 메모, 독립 Personal Note, 간결한 Devotion, Check-in 카드, Class Review 단일 시각 배치 — 구조 유지.
- 390px 다크 **Review → Archive → Mood**: 월간 달력·선택 날짜·Morning/Evening·Open Daily Review·하단 탭 정렬 정상, 설명 글자가 작음.
- 320px 라이트 **Write**: 양 이모지가 주변 아이콘보다 연하고 명확하지 않음, More는 제자리.
- 1024px 라이트 **Plan**: 폭은 모바일 PWA 기준의 중앙 열, 표의 두 열과 행은 정렬됨.

## 정렬 통과 기준
- 320·390·1024px의 현재 표시 상태에서 가로 스크롤 및 화면 밖 컨트롤 **0건**.
- Plan 연결 메모를 독립 Personal Note로 합치지 않음.
- Focus/Prayer/Devotion은 독립 카드 대신 간결한 활동 로그.
- Morning/Evening 체크인은 동일 날짜에서 별도로 표시.
- Class Review 타임스탬프 중복 없음.
- Archive Mood 조회가 기존 검색어·필터·저장 기록을 변경하지 않음.
- 라이트·다크에서 본문 대비 및 모달 키보드 기본 동작 유지.
