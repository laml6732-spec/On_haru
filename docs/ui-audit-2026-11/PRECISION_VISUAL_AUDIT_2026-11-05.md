# On_HARU — 컨설턴트식 정밀 UI 검수 (2026-11-05)

## 목적과 판정 기준
**사용자 질문:** “컨설팅펌 PPT 정렬 검수에서도 살아남을 수준인가?”

이 감사는 단순한 클릭/저장 QA와 분리해 **동일 위계의 정렬선, 간격, 글자 크기, 시각적 무게, 터치 영역, 모바일/PC 일관성**을 확인한다.

**결론:** 구조적 정렬은 양호하나, 디테일을 엄격하게 보는 최종 프레젠테이션 검수에는 **조건부**이다. 특히 좁은 모바일의 주요 터치 영역, 보조 설명 글자 크기, Listening 양 아이콘의 광학적 가독성은 보완할 가치가 있다.

| --- | ---: | --- |

| Archive Mood 콘텐츠 왼쪽 | 14px | 내부 2px 패딩으로 해석, 시각적 오차 확인 |

| Write Listening 양 아이콘 / 칩 | 34×34px / 40×36px | 색 대비를 높이고 히트 영역 별도 조정 |
| Plan `#konaScheduleMore` | 32×32px | 40~44px 수준 검토 |
| Check-in 시간 입력 | 높이 38px | 40~44px 수준 검토 |
| Focus 타이머 | x=68.6, 너비=182.9, 중심 ≈ 160.05px | 화면 160px 중심과 거의 일치: **유지** |
| Mood 날짜 | 40×43px | 7열 너비 유지, 터치 높이 보강 |

## 컨설턴트식 정렬 판단 원칙
- **같은 레벨만 같은 기준선**: Plan 부모→하위 메모는 들여쓰기가 맞음. 개인 메모에 일괄 들여쓰기 적용 금지.
- **메타정보와 본문 거리**: Devotion 메타가 기록 본문과 연관되도록 보여야 함. 세션 자체는 짧은 활동 로그 유지.
- **강조색은 의미**: 사용자 형광펜은 콘텐츠 강조이고, 시스템 칩과 구분되어야 함. 임의로 제거/채도 수정하지 않음.
- **최소 변경**: 여백만 개선할 때 저장 구조·시간 분류·데이터 링크·아이콘의 의미를 바꾸지 않음.
- **대칭과 광학적 중심 구별**: CSS 중점 정렬 + 캡처 이미지 확인이 모두 필요.

## 미검증 한계
- 픽셀 좌표가 맞아도 모든 화면의 광학적 완성도를 보증하지 않음. 정량 검사에서 캡처한 이미지도 함께 사람의 눈으로 검토해야 함.
- 한국어/영어 조합별 모든 길이, 커스텀 폰트 확대, 실제 Android 및 iOS 기기의 노치·소프트키보드·PWA 설치/업데이트는 포함되지 않음.
- 스크린샷 합성 기록이 실제 장기 개인 데이터의 모든 조합을 재현하지는 못함.
- 기존 기능 QA는 PWA 아이콘 실패 때문에 전체 배포 승인과 구분됨.
