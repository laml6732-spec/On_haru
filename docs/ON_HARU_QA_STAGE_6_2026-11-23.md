## 수정과 재현

돌아보기의 메모 편집창을 열면 본문을 먼저 선택한 뒤 다음 프레임에 공통 모달 코드가 제목으로 포커스를 옮겼다. 열자마자 입력할 때 제목에 글이 들어가 본문이 그대로 남을 수 있었다. 모달에 이미 포커스가 있는 경우 기본 포커스 처리를 건너뛰도록 수정했다. 이전 코드에서는 새 포커스 단언이 **4/4 환경에서 실패**했고 수정 후 **4/4 환경에서 통과**했다. 수정 환경은 320px 영문 라이트, 390px 한글 다크, 390px 영문 라이트, 1024px 영문 라이트다.

기존 및 신규 Chromium 스위트 9개, 반응형 16개 환경의 조건 210개, 정적 UI 17개, Worker 릴리스 검사 단위 테스트 17개, 지표 계약 검사를 통과했다. PWA 검사에서도 HTML과 서비스 워커의 릴리스 표식, 오프라인 셸과 저장한 메모를 확인했다. Worker 테스트는 가상 릴리스 응답을 사용했다.
